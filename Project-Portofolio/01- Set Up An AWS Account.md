## Introducing Today's Project!

In this project, I am setting up my first AWS account to start building cloud projects. To ensure my setup is secure and budget-friendly, I will explore the AWS Free Tier, configure billing alerts to prevent surprise charges, and protect my root user credentials with MFA.

### Key tools and concepts

Key Tools Used:
1. AWS Management Console: To register the account, verify identity, and configure security.
2. AWS Billing and Cost Management: To check billing preferences and enable usage alerts.
3. MFA Authenticator: To set up multi-factor authentication for root user security.

Key Concepts Learnt:
1. AWS Account Registration: How to establish a new account, configure payment details, and complete identity verification.
2. AWS Free Tier Structure: The differences between Always Free, 12 Months Free, and Short-Term Trials.
3. Alert Preferences: Enabling email alerts at 85% of Free Tier limits to prevent unexpected charges.
4. Root User Protection: Securing administrative access with strong passwords and MFA.

## Creating My AWS Account

In this step, I am going to sign up for a new AWS account, verify my email address, and set a strong root user password to ensure my account is safe and secure.

### Understanding the root user

The root user is the main account owner with absolute, unrestricted access to every service, configuration, and billing detail in the AWS account. Creating a strong password is critical because if this account is compromised, an attacker gains total control over your entire cloud infrastructure, sensitive data, and billing settings.

## Setting Up Billing and Payment

In this step, I am going to select the Free account plan, enter my contact details, and add a payment method for identity verification to ensure my account is ready to go.

### Why AWS requires a payment method

AWS requires a payment method to verify my identity and ensure I am a real person, not a bot. It also ensures AWS has a billing method on file if my resource usage goes beyond the Free Tier limits. To verify the card, AWS only performs a temporary $1 authorization hold that is fully reversed within a few days.

## Completing Account Activation

In this step, I am going to verify my identity using my phone number and select the free Basic support plan. Since I am using this AWS account to learn, explore, and build practice projects, this plan is perfect for starting my cloud journey.

### Identity verification and support plan

I verified my identity by entering my mobile number and submitting the verification code I received via SMS. The Basic support plan is free and includes 24x7 self-service access to AWS documentation, customer service forums, and AWS Trusted Advisor checks.

## Enabling Free Tier Alerts

In this step, I will log in to the AWS Console, navigate to Billing Preferences, and enable Free Tier usage alerts. This will prompt AWS to email me if my resource usage reaches 85% of my Free Tier limits, protecting me from unexpected charges.

### Why usage alerts matter

I set up usage alerts because AWS will email me when my usage reaches 85% of a Free Tier limit. This proactive alert gives me time to stop or adjust my resources before any unexpected charges occur, protecting me from surprise bills.
