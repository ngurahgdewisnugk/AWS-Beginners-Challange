## Static Website Hosting on S3

### What I did in this step

In this step, I will make the static websites available publicly this step is important because the website will do hosting and  can be accessly via online.

### Understanding website hosting

`Website hosting` is what makes your website public on the internet. Even if you perfect an HTML file, no one else can see it when it's stored as a local file on your computer!. `Website hosting` storing your HTML file (and the other files for your website) on a web server, so it's accessible online.

By configuring your S3 bucket for hosting, we're telling this bucket: </br>
> _"please create a URL that will take anyone to a page that displays the HTML file I just uploaded."_

### How I enabled website hosting

To enable `website hosting` with my S3 bucket :  
1. I going In the `Properties` section of my bucket, then enable `Static website hosting`.
2. After That, choose `host a static website` on `hosting type section`.
3. Then, Specify the index documents with the file that has already uploaded on step 2 with naming `index.html`

### Access Control Lists (ACLs)

An ACL is to configure permission setting that setting to determines who can access a specific resources, in example :  
> if amazon S3 Buckets have a 200 objects, In S3 buckets, only three objects can be configured to be accessible by other AWS accounts. I Keep Enable ACLs, to know how to ACLs work, and compare with the Disable ACLs later.

## Bucket Endpoints

### Understanding bucket endpoint URLs

Once static website is enabled, S3 produces a bucket endpoint URL, which is the URL to access the static website via online that you're hosting.

### What I saw when I tested the endpoint

When I first visited the bucket endpoint URL, I saw `HTTP error 403 Forbidden`. The reason for this error was that my objects in a bucket are `public by default`, but the website files in the objects of my buckets are still `private`. Therefore, **it is necessary to separately open access to the files in the bucket** so that they can be accessed publicly and the content on the website can be viewed.
