## What is Cloud?

Before cloud computing, apps and data ran on your device. Now, companies like AWS and Google host this in huge data centers, letting you access powerful computing over the internet—saving space and boosting performance.

### What is AWS?

AWS is a cloud computing platform created by Amazon. Instead of storing files or running apps on your own computer or company servers, AWS lets you do all that over the internet using Amazon’s powerful data centers.

AWS professionals help build and maintain cloud applications Some popular cloud career paths include Cloud Architect, DevOps, Cloud Enginner etc. I'm most interested in Cloud Architect
